# MealTime

MealTime is an evolving web-based platform designed to help users explore restaurant menus near my city Solan Himachal pradesh, find food recommendations, and navigate various meal categories.

## 🚧 Project Status

This project is **currently under development**. We are actively working on adding new features, refining the user interface, and improving functionality. Stay tuned for updates!

## 📌 Features (Work in Progress)

- **Sidebar Navigation:** Quick access to different sections like Home, User Account, Review, and Contact Us.
- **Search Functionality:** Easily search for meals based on user preferences. ## still not working
- **Recommendations:** Displaying curated food options with pricing.
- **Menu Categories:** Categorized food items for seamless browsing.
- **Restaurant Listings:** Explore various restaurants and their offerings.

## 🔧 Technologies Used

- HTML5 & CSS3
- JavaScript (with jQuery)
- Ionicons for icons
- Google Fonts for typography
- External stylesheet integration
